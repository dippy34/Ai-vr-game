# Notes for AI coding assistants

Start with `docs/HANDOFF.md` (project state, how to run and deploy, code map, known traps, and the
prioritized next steps). The architecture rules are in `CLAUDE.md` and apply to every assistant.
The game design is in `docs/DESIGN.md` (today) and `docs/STORY.md` (the agreed future direction).
Every push to the default branch deploys to GitHub Pages, so run `npm test` and `npm run build`
first.
