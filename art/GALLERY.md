# MUTE model gallery

Every model is generated by a Blender script in `art/blender/` (see `art/README.md`).
Renders below are Blender previews (`*_3q`, `*_flash` = in-game camera-flash lighting) and
screenshots from the actual three.js game renderer (`*_threejs`).

**28 models in the game:** `avatar_body`, `avatar_head`, `camera`, `door`, `dressing_chair`, `film`, `furniture_bed`, `furniture_cabinet_low`, `furniture_cabinet_narrow`, `furniture_cabinet_tall`, `furniture_couch`, `furniture_counter_module`, `furniture_counter_sink`, `furniture_counter_stove`, `furniture_crate`, `furniture_desk`, `furniture_nightstand`, `furniture_piano`, `furniture_shelf_module`, `furniture_shelf_module_b`, `furniture_table_coffee`, `furniture_table_dining`, `furniture_table_small`, `fuse`, `fusebox`, `hand_left`, `hand_right`, `monster`
